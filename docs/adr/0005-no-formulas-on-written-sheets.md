# Books 與移交紀錄不放互相引用的公式

每次同步都會寫入移交紀錄與 Books 的保管人欄。引用這兩個分頁的公式（例如每列各查一次整張表的 `COUNTIF`），或 volatile 函式（`NOW`、`TODAY`、`INDIRECT`、`OFFSET`），會在每次寫入後重算；下一次同步讀 Books 時要等重算完成，同步就會變慢。名單 800 人、600 筆紀錄的報到系統上，這類公式讓 8 台裝置同時寫入從每筆 1–3 秒變成 1–15 秒。

## Consequences

- 統計、依班級列出書單這類需求放在另一份試算表，用 `IMPORTRANGE` 讀資料；或直接在 Books 上用篩選。
