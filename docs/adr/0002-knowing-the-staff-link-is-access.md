# 知道工作人員連結就能刷書，沒有帳號系統

Web App 部署成「所有人（匿名）」可存取，掃描頁靠網址 hash 裡的部署 ID 連到這份試算表的後端；老師不登入，也不記錄是誰刷的。刷書是園內低風險的操作，帳號系統會讓每位老師多一道手續。hash 不會被瀏覽器送到 GitHub Pages 的伺服器。

## Consequences

- 任何拿到連結的人都能讀到書目（主條碼、書名、位置、借閱班級、借閱人）與幼兒名單（各班幼兒全名），並且能刷書。園方決定先用全名，連結外流時名單也跟著外流；要改善時，名單改成只寫名字或座號，或在掃描頁前加一道密碼。
- 每個請求在處理前都驗證格式與大小；異動的位置必須在班級清單裡，借閱的幼兒必須在幼兒名單裡。
- 被亂刷的書可以從異動紀錄查回原本的狀態；異動紀錄的「入口」欄能分辨是哪一台裝置。
