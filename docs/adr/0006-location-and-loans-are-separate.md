# 位置與借閱分開記，還書時書留在刷還書的班級

每冊在 Books 上記「位置」（學校、某一班，或借出中）與借閱欄（借閱班級、借閱人、借閱日期）；借閱紀錄一次借閱一列，借閱時新增，歸還時只填那一列的歸還日期，不覆蓋之前的借閱。書屬於誰不另外記：園方的書全部屬於學校，多一欄只會是一欄永遠相同的值。

還書不是獨立的動作：在放置模式刷一本借閱中的書，就是歸還，位置改成所選的班級。小朋友在海洋班把書還給老師，書實際留在海洋班教室；如果一律回到學校，位置欄就和書實際的位置不符。要送回圖書區時，選「學校」再刷一次。

## Considered Options

- **還書一律回學校**：園方最初的提議。和實際位置不符的原因如上。
- **借閱中的書被刷借給另一位幼兒時拒絕，要求先還書**：書在老師手上就表示前一位已經還了，多一步只是讓老師切換模式。現在的做法是自動記前一位歸還、再借給這位，異動紀錄的動作是「換人借閱」。

## Consequences

- 借閱紀錄的列號存在 Script Properties，寫入前以借閱編號（借閱那一筆異動的 scanId）核對；有人排序或刪列時改用借閱編號搜尋。
- 復原借閱時，借閱紀錄那一列填上歸還日期並在備註寫「刷錯復原」，不刪列。復原歸還時，清掉原本那一列的歸還日期，不另開一列。
- 復原「換人借閱」會把前一位的借閱重新開一列，借閱日期是復原當天，原本那一列維持已歸還。
- 「已歸還」不是狀態，只表現在借閱紀錄的歸還日期：剛還的書和一直在學校的書，篩選「在館」時要一起出現。
