# 掃描頁先判定，Apps Script 是唯一寫入者

刷書在掃描頁上用書目快取判定結果後立刻顯示，移交放進佇列，背景每幾秒批次同步給 Apps Script；Apps Script 是唯一寫入試算表的一方，同步回應順便帶回其他入口的移交。Apps Script 每次往返約 1 秒以上，老師連刷幾十本時不能每本都等。

## Consequences

- 兩個入口在同步之前（約 3 秒內）把同一冊移到不同保管人時，兩邊都會顯示成功，最後以 seq 較大的為準（ADR-0003）。同時移同一冊本身就是操作錯誤，移交紀錄裡兩筆都在。
- 離線時禁止刷書：只有「最近一次同步失敗」，或「請求超過 10 秒沒回應且瀏覽器回報沒有網路」才算離線。Apps Script 偶爾會有十幾秒的回應，只是慢不能鎖住入口。佇列只放在記憶體，離線時繼續刷、再關掉頁面就會遺失，所以不允許。
