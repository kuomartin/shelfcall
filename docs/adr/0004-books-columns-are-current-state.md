# Books 的位置與借閱欄是目前狀態，異動紀錄是歷史

每冊的目前狀態以 Books 分頁上的「位置」「借閱班級」「借閱人」「借閱日期」為準，管理者可以直接在試算表上修改；異動紀錄只記錄掃描頁做過的異動，不用來重算狀態。現有的書在導入時就有位置，卻沒有任何異動紀錄，以欄位為起點最自然，手動修正也不會被程式蓋回去。「狀態」欄由程式依位置寫入，只是為了方便篩選。

掃描頁開頁時下載書目快取，快取帶著讀取 Books 之前的 seq。掃描頁只把 seq 更大的異動套在快取上：更早的異動已經寫進 Books，再套一次會蓋掉之後的手動修改。因為 Books 是在放開 lock 之後才寫入（ADR-0003），一分鐘內記帳的異動可能還沒寫進 Books，所以快取的 seq 會退到這些異動之前。

## Consequences

- 手動修改 Books 不會出現在異動紀錄裡，也不會更動借閱紀錄。手動把一冊改成借出中，借閱紀錄沒有那一列；之後刷還書時依主條碼找不到還沒歸還的列，就只更新 Books。
- 一分鐘內對剛被刷過的同一冊手動修改，可能在某台掃描頁上被那筆異動蓋過，直到書目重抓。
- 異動的「從」是掃描頁刷書當下看到的狀態，不是伺服器寫入時欄位上的值。
