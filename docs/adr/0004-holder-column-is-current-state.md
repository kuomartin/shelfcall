# Books 的保管人欄是目前狀態，移交紀錄是歷史

保管人以 Books 分頁上的「保管人」欄為準，管理者可以直接在試算表上修改；移交紀錄只記錄掃描頁做過的移交，不用來重算保管人。現有的書在導入時就有保管人，卻沒有任何移交紀錄，以欄位為起點最自然，手動修正也不會被程式蓋回去。

掃描頁開頁時下載書目快取，快取帶著讀取 Books 之前的 seq。掃描頁只把 seq 更大的移交套在快取上：更早的移交已經寫進 Books，再套一次會蓋掉之後的手動修改。因為保管人是在放開 lock 之後才寫入（ADR-0003），一分鐘內記帳的移交可能還沒寫進 Books，所以快取的 seq 會退到這些移交之前。

## Consequences

- 手動修改保管人不會出現在移交紀錄裡。
- 一分鐘內對剛被移交的同一冊手動修改，可能在某台掃描頁上被那筆移交蓋過，直到書目重抓。
- 移交的「從」是掃描頁刷書當下看到的保管人，不是伺服器寫入時欄位上的值。
