# shelfcall

書籍借閱登記：Books 分頁記錄每一冊書現在在哪個班級、被哪位幼兒借走，借閱紀錄分頁一次借閱一列。老師在掃描頁選定班級後連續刷書，掃描頁在本機立刻判定，Apps Script 批次寫入並同步各入口。

用語見 [CONTEXT.md](CONTEXT.md)，設計決策見 [docs/adr/](docs/adr/)。

## 給管理者

### 試算表

`Books` 分頁第 1 列是標題，程式依標題名稱找欄位，欄位順序不拘。

| 欄位 | 必要 | 說明 |
|---|---|---|
| 主條碼 | 是 | 每冊一個、不可重複。欄位格式要設成「純文字」，否則 `000070` 會被存成 `70`，刷條碼時對不到 |
| 書名 | 是 | 刷書時顯示 |
| 位置 | 是 | 「學校」、班級名稱或「借出中」，班級要和設定裡的班級清單一致。程式會改寫，也可以手動修改 |
| 借閱班級、借閱人、借閱日期 | 是 | 借閱中才有值，程式寫入，歸還時清空 |
| 狀態 | 是 | 程式依位置寫入：在館、班級使用中、幼兒借閱中，方便篩選 |
| 更新時間 | 否 | 有這一欄的話，程式寫入時一併寫入時間 |

`幼兒` 分頁（第一次開 Web App 網址時建立）：`班級`、`座號`、`姓名`，一位幼兒一列。班級要在班級清單裡，同班不可同名；座號決定掃描頁上的排列順序，可以空白。新生、換班直接改這個分頁，開著的掃描頁會在下次同步時更新名單。

其他欄位（ISBN、作者、分類……）程式不讀也不寫。`異動紀錄` 與 `借閱紀錄` 分頁由程式建立與寫入，不要手動編輯；借閱紀錄的「歸還日期」空白就是還沒歸還。

Books 上不要放引用 `異動紀錄`、`借閱紀錄` 或位置、借閱欄的公式，也不要用 `NOW`、`TODAY`、`INDIRECT`、`OFFSET`：每次同步寫入都會觸發重算，同步會變慢。統計放到另一份試算表，用 `IMPORTRANGE` 讀資料。

### 從保管人欄升級

1. Books 的 `保管人` 欄改名為 `位置`，新增 `借閱班級`、`借閱人`、`借閱日期`、`狀態` 四欄（可以空白）。
2. 舊的 `移交紀錄` 分頁改名為「移交紀錄（舊）」保留；新的 `異動紀錄` 由程式建立，seq 接續。
3. 推送新版程式後，在「部署 → 管理部署作業」把網頁應用程式更新到新版本，再用瀏覽器開一次網址，建立 `借閱紀錄` 與 `幼兒` 分頁。
4. 在 `幼兒` 分頁填入各班名單，執行「保管 → 檢查書目」修正到沒有問題為止。

### 第一次設定

1. 在試算表「擴充功能 → Apps Script → 部署 → 新增部署作業」，類型選網頁應用程式，執行身分「我」，存取權「所有人」。
2. 用瀏覽器開一次部署出來的網址，依指示授權，看到「已完成初始化」。
3. 回到試算表，選單「保管 → 設定」填入班級清單（「學校」一定在清單裡）。
4. 在 `幼兒` 分頁填入各班名單。
5. 選單「保管 → 檢查書目」：列出 Books 沒有條碼、條碼重複、條碼存成數字、位置或借閱欄不一致，以及幼兒分頁班級不在清單、同班同名的列，修正到沒有問題為止。
6. 選單「保管 → 工作人員連結」，把連結或 QR code 交給老師。知道連結的人看得到幼兒名單。

### 刷書

- 先在頁面上方選班級，再選模式。
  - **放置／還書**：刷到的書放到所選的班級。借閱中的書刷了就是還書，書留在所選的班級；要送回圖書區就選「學校」再刷。
  - **借閱**：點選一位小朋友，之後刷的每一本都借給這位小朋友，直到點別人或換班。書如果還在別的小朋友名下，會自動記那位小朋友已還、再借給這位。選「學校」時不能借閱。
- 三種結果各有不同的提示音：有異動（高音一聲）、已經是這個狀態（兩聲）、找不到條碼或還沒點選小朋友（低音）。
- 刷錯了，在「最近刷過」按「復原」。書之後又被刷過時不能復原。復原借閱時，借閱紀錄那一列會填上歸還日期並註明「刷錯復原」。
- 頁面最下方列出所選班級借閱中的書。
- 可以用相機掃 QR code、Code 128、Code 39，也可以接 USB 條碼槍或直接輸入條碼。
- 多台裝置可以同時刷。離線時禁止刷書。

## 結構

| 目錄 | 內容 |
|---|---|
| `core/` | 純 TypeScript 領域邏輯：書目快取、幼兒名單、刷書判定、同步與借閱紀錄的增改、請求驗證。不依賴 Apps Script 或 DOM，用 `node --test` 測 |
| `gas/app/` | 綁定試算表的 Apps Script：Web App API、選單、對話框 |
| `web/` | 掃描頁，GitHub Pages 提供（`main` 推送後由 `.github/workflows/pages.yml` 部署） |
| `scripts/build.ts` | esbuild 打包，輸出到 `dist/` |

Apps Script 只認得頂層函式，所以建置時會替 `gas/app/main.ts` export 的每個函式，在檔尾補一個同名的頂層函式。

## 指令

```bash
npm test
```

```bash
npm run typecheck
```

```bash
npm run build
```

推送 Apps Script 用 `npx clasp push`，`.clasp.json`（不進版控）的 `rootDir` 指向 `dist/gas/app`。`npm run build -- --dev` 的建置多出端到端測試用的 `devReset`（清空異動紀錄、借閱紀錄與借閱記帳，設定班級清單）與 `devDump`（讀回異動紀錄、借閱紀錄與指定條碼在 Books 上的狀態欄位）。
